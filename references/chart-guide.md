# 图型基础导向

首次选型、原图型不明或拟更换时读取。用户指定且合理、已有图型也合理时直接沿用；不为换风格而重新选型。下表是优先方向，不是排他禁止表。

| 意图/已有结果 | 默认优先 | 必要的判断与保真要求 |
| --- | --- | --- |
| 时间或有序自变量趋势 | 折线 | 保留顺序、缺口与已有采样点；不把无序类别连成趋势，不额外平滑 |
| 类别、方案比较 | 柱状/条形 | 长类别名优先横向；柱长编码通常从零开始；自然顺序不改，无序类别才考虑按值排序 |
| 单时点构成 | 饼图/堆叠柱 | 分母与类别覆盖应明确；类别多或需精确比较时优先条形/堆叠，不常规用 3D |
| 已有拟合结果 | 实测散点 + 已有拟合曲线 | 有共同有序自变量才连拟合线；实测—预测对应散点不硬连线；保留已有训练/测试口径，不重拟合 |
| 两个变量关系 | 散点 | 不自行加回归线、置信带、显著性符号或抽样删点 |
| 矩阵、相关性、二维强度 | 热力图 | 保留行列标签、缺失值、色标单位与范围；数值不默认插值，密集矩阵不强行逐格标数 |
| 已有参数扰动结果 | 单因素折线；双因素热力/等高线；影响排名条形/龙卷风 | 不补做扰动试验；保留基线、范围与指标口径，不因为画了灵敏度图就断言稳健 |

## 省推理默认

- 分类色先用少量协调色，常见任务 2–4 色、多线常见不超过 5 条；超出后先考虑分面或线型，不为了满足数字合并类别或丢弃曲线。
- 已有图合理时保持图型。类别名太长先横向或调整布局；多系列分不清先用线型/标记辅助，不立即更换分析表达。
- 占比随时间变化可用折线；离散时段的量可以用柱状；原课程口诀不转化为一律禁止。
- 课程未列的合理专业图（如 ROC、森林图、箱线图）保持其领域含义，按通用规范审查；不硬套成五种基础图。
- 涉及直方分箱、聚合、归一化、坐标变换或从保存结果派生新指标时，沿用明确的原口径；没有依据时先问，不把统计决定藏进图型选择。
