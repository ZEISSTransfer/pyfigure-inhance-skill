# 首次绘图

仅首次绘图模式读取。本流程不重复共用底线；沿用入口及样式、检查参考。

## 确认已有信息

从当前任务、结果说明和相关代码找出：这张图表达的事情，保存结果的来源，字段含义、单位及必要分组，以及论文预计使用尺寸。只读相关文件，不扫描无关的全部资料。

缺数据、关键单位或结果口径时，先完成可确定部分并集中问缺项；不从截图估数、不临时模拟数据冒充结果。可使用明确标为测试的隔离示例验证环境，但不能作为用户结果交付。

## 选型与编写

1. 用户指定且合理的图型直接采用；否则按图型参考的基础导向选择，不常规生成多套候选消耗额度。明确错配时解释并按同一数据含义修正。
2. 查项目是否已有共用样式模块和输出约定。复用合适的模块；没有时按样式参考复制模板。新模块不改变现有图的默认行为，接入范围仅为当前目标。
3. 编写可单独运行的绘图入口，只读取必要的保存结果。使用原有字段、分组及精度；已有计算结果不在绘图脚本中重算。需要聚合或转换而任务与原分析均未定义时，先明确口径。
4. 文件读取路径相对于明确的项目或脚本位置解析，不依赖碰巧的工作目录。图代码要保留数据来源、运行方式和必要的单位说明，不要求建立新的数据格式。

首次选色与人工多次试色按 [palette-guide.md](palette-guide.md) 执行。先读项目默认；尚未确认时用临时起点并说明未确认。人工可反复要求只换颜色，不重选图型或改数据、布局；明确认可为后续默认后才更新项目配置。更换默认不自动重绘旧图。

## 运行与交付

检查调用链是否会触发建模、重写数据或额外出图；安全时运行。环境不可用或无法安全单独出图时交付代码和阻碍，不声称已经生成或验证。

按共用检查清单查看保存后的成图，再按入口的一轮上限处理明确问题。交付应能让用户从项目内运行入口重现图片；不要只提供脱离源码的最终图片。
